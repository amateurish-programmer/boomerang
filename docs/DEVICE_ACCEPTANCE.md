# 真机验收记录

本表用于补齐真实设备证据，不代表已经执行。使用专用测试账号和合成内容；记录手机型号、Android版本、APK版本、时区及实际结果。自动化模拟器报告另见阶段集成报告。

| 项目 | 操作与预期 | 实际结果 |
|---|---|---|
| 候选升级 | 已装0.3.0签名候选时直接安装同证书0.3.1；原记录、修订和来源仍在。Debug证书不同，先导出备份再卸载安装。 | 待验收 |
| 邮箱与账号隔离 | 在应用注册并由邮箱本人完成验证；登录A创建记录，退出后登录B，A记录不可见；匿名数据仅明确预览选择导入后归属账号。 | 待验收 |
| 双设备离线冲突 | 两台手机登录同一专用账号，先同步同一条合成记录；分别断网修改，再依次同步。冲突保留双方内容和历史，由用户选择，失败不能丢失本地修改。 | 待验收 |
| 通知拒绝与恢复 | Android13+实际拒绝通知权限；到期提醒仍在通知中心。点通知设置开启后返回，关闭提示消失；新提醒可投递，已拒绝时保存的旧提醒不补发重复提示。 | 待验收 |
| 系统通知点击 | 点通知进入准确记录；切换账号后旧通知不得进入新账号相同编号的记录，旧账号任务应取消。 | 待验收 |
| 后台与重启 | 创建到期前7天、1天及当天的合成记录，记录系统省电设置、锁屏/重启/长期后台的实际提醒时间。WorkManager不承诺准点；回前台应补查，重复扫描不连续补发三条。 | 待验收 |
| 修改与胶囊 | 修改截止日、取消或删除后旧系统提醒撤销；封存胶囊后原话、日期及验证标准不可改，仍可追加说明，历史保留。 | 待验收 |
| 系统文件提供方 | 分别用手机自带文件管理器、实际使用的云盘导出再导入。取消不改数据；预览后选择跳过/替换才写入；账号切换后旧选择器返回不得串账号。 | 待验收 |
| 回旋卡 | 预览中文长文排版与来源，私人备注不得出现；只有本人明确选择系统分享目标后才发送。记录所用分享目标，不替别人发送测试信息。 | 待验收 |

百炼真实 analyze/chat/search/extractor/周报，以及 Cron→复核→通知→用户确认，是另一组依赖服务配置的验收。用户暂缓百炼期间，保持生产 Cron 关闭，不把合成响应测试或模拟器通过视为真实供应商通过。
