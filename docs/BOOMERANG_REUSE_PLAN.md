# 复用决策

采用独立仓库，不克隆后删账本功能。复用已验证的构建版本组合和官方 Gradle Wrapper，保留其来源；借鉴同步版本检查、显式冲突、RLS 与 PostgreSQL CI 的方法，重写本项目业务实现。

可复用：JDK17/AGP/Kotlin/Compose/Room 版本组合，云端构建流程结构，测试分层，服务端保密方式。

不可复制：家庭/成员权限、金额汇总、Excel 导入、账本数据、Supabase 项目 ID/密钥、更新服务地址、旧 APK 签名。回旋镖采用个人账号隔离；共享和社区不在 V1。

新项目包名 `com.boomerang.app`。工具凭据只用于用户授权的 GitHub 操作，不写入项目。构建依赖后续升级走独立兼容验证。
