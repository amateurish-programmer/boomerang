# 水墨武侠 UI-D2 实施计划

> 使用 subagent-driven-development 实施并独立审查。本阶段目标是可构建、可回归的 Android 核心页面改版。

**Goal:** 将用户确认的宣纸朱砂风格落地到主题、导航、首页、镖库、编辑和详情。
**Architecture:** 保留 Compose → ViewModel → Repository；仅改 UI 呈现和必要导航回调。
**Tech Stack:** Kotlin / Compose Material 3，minSdk 26，现有依赖。
**Spec:** `docs/design/ink-wuxia/README.md` 与同目录 `index.html`。用户最新修改：移除品牌旁“记言”红色小印章；不在任何页面重新加入。

## Global Constraints

- 不修改数据库、同步、AI 确认、日期与胶囊业务规则；真实数据与演示数据严格分离。
- 原话、证据、AI建议、用户确认分开呈现，未知日期不能猜测，截止当天包含在期限内。
- 主题使用宣纸 #F5F1E8、墨黑 #24231F、朱砂 #9D302B、辅助文字 #625D55；夜墨背景 #222520、文字 #F0ECDF、朱砂 #D99A85。
- 字体使用现有系统字体，标题 Serif / 正文 SansSerif，不捆绑未授权字体；无红色小印章。
- 控件触控目标至少 48 dp；正文使用 sp；支持长文、空态、加载、错误、系统字号；不通过固定高度截断重要信息。
- 所有业务交互只通过现有回调/ViewModel，不直接增加网络或数据库调用。
- 保留既有 testTag；确因导航结构改变而更新对应测试，不能删除业务断言。
- 不在用户手机上安装测试包或清数据；设备测试由云端隔离模拟器完成。
- 签名提交使用实际 Git 身份，父代理负责整合与发布，不由实现代理推送。

### Task 1: 核心页面整体实现

**Files:** `ui/Theme.kt`, `ui/BoomerangApp.kt`, `ui/Screens.kt`, `ui/RecordEditor.kt`, `ui/RecordDetailScreen.kt`；必要时新增 `ui/InkComponents.kt`；测试 `androidTest/.../InkUiTest.kt`、既有 `ShellNavigationTest.kt` 及受影响 UI 测试。

**Interfaces:** 保持现有页面参数契约和 testTag；首页可追加默认 `onLibrary: () -> Unit = {}`，由 App 传入 `model.select(Destination.LIBRARY)`。不要添加无真实入口的通知或分享按钮；现有分享仍从“回顾、分享与备份”可达。

- [x] 写有意义的 Compose 行为测试：筛选底部弹层取消不改变筛选/应用后更新；详情来源/历史切换后仍可编辑；低频删除必须经更多菜单及确认；编辑在长表单底部滚动时保存保持可达、未保存草稿返回恢复。新增测试或更新旧交互步骤，保留离线 CRUD 等现有断言。
- [x] 先编译测试并记录缺少新交互的失败证据；无本地模拟器时由父代理云端执行。不能将仅编译测试记作运行通过。
- [x] Theme：完整亮暗语义配色、宋体标题/黑体正文、8–12 dp 小圆角；抑制默认紫色/大药丸按钮及突兀 tonal elevation。
- [x] App：四个导航入口改为干净的纸面、细分隔、墨色未选中、朱砂选中；保留入口、状态恢复及账号隔离 key。不要动其余页面业务。
- [x] Home：手绘 Canvas 远山用于顶部品牌区，无印章；待跟进条目清晰列出类型/主体、原话、期限与结果；新建操作固定、可触达，不遮挡可读内容；“全部记录”真实导航。使用 LazyColumn 保持大量记录流畅，保留空态/失败重试。
- [x] Library：紧凑标题/新建、单行搜索、类型/结果筛选弹层、排序菜单；应用筛选才触发回调，取消保留旧值。全部五种类型和六种结果仍可选。使用有稳定 key 的 LazyColumn，清楚的空结果与错误态。保留搜索和 create_record 标签。
- [x] Detail：原话优先，主体/日期/时区和确认结果准确；验证/来源/历史分层，不隐藏未知日期和历史快照；编辑固定底部。删除和胶囊封存移入更多菜单，保留确认对话框及胶囊提示。对 busy/空详情禁止危险操作。保存原有错误及加载状态。
- [x] Editor：分组阅读；主信息、期限与验证标准、来源、主题备注；保存固定底部并避让键盘；返回/输入/选项在 busy 时禁用；任何错误字段在折叠区自动展开并可滚动到达；保留用户输入、全部字段与胶囊校验现有业务。日期仍允许明确输入/未知，不引入猜测。
- [x] 添加独立合成数据 UI 测试截图：浅色首页/镖库/详情、暗色详情、大字体编辑；写到测试 app files 的 acceptance/ink-ui 下，不含真实账号或用户记录。
- [x] 验证：`bash android/gradlew -p android testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest`，父代理执行云端设备矩阵。记录未验收项目。
