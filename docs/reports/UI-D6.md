# UI-D6：青绿山水动态浏览器样板

日期：2026-10-02。状态：动态实现、本地行为测试、浏览器布局/交互检查与独立复审完成；实际运动强度待用户确认后进入UI-D7。

## 范围与产物

UI-D5静态构图已获用户“可以，继续”确认。保留原创宣纸/夜墨完整山水、品牌留白与首页结构，在独立装饰层增加两层谷地云雾和每版32个不规则墨尘粒子；山体保持稳定，滚动只给装饰层最多6px轻微视差。没有恢复品牌印章，没有灰度山图拼接。

- [动态样板](../design/ink-wuxia-v2/index.html)：主题对照、完整/减少/关闭、重播入口、固定演示记录与输入窗口。
- 完整模式有800/500/350ms入场渐显；减少模式只有160ms短淡入和180ms完成颜色反馈，没有循环粒子/视差；关闭模式取消过渡与反馈。系统减少设置限制完整模式的有效强度。
- “记下原话 → 完成预览”在原主按钮附近触发最多8个朱砂微粒，约450ms渐散；Escape/关闭丢弃草稿、不触发完成。所有输入只存在于演示DOM，未保存或上传。
- [调度核心](../design/ink-wuxia-v2/motion.mjs)与[浏览器适配](../design/ink-wuxia-v2/landscape-motion.mjs)：有限入场、循环绘制和完成反馈分别处理。Canvas仅装饰、不可拦截操作、DPR最多2，绘制节流上限30fps；这是源码约束，不是真机帧率测量。
- [实施计划](../plans/2026-10-02-ink-motion-sample.md)与新增截图preview-motion-both.png、preview-motion-light-360.png、preview-motion-dark-360.png；保留UI-D5静态截图和原画。

## 本地与浏览器证据

`node --test scripts/test-ink-motion.mjs`最终25项通过、0失败/跳过；先观察缺失模块/导出的RED，再实现GREEN。覆盖系统减少上限、单循环、取消与迟到回调、恢复首帧dt=0、dt上限50ms、永久销毁、绘制内停止、有限入场可用性、减少反馈保留/取消、视差边界。四份JS语法检查及`git diff --check`通过。

修复前绘制层截取的连续PNG在full下不同、off下逐字节相同，支持样板确有运动且关闭后静止；不据此宣称性能/FPS或Android验收。修复只改变生命周期/反馈，不改变山景绘制。

浏览器可见性能力隐藏窗口不会改变`document.hidden`，因此本轮不将该操作算作后台事件通过；后台策略由确定性行为测试及源码复审覆盖，真实浏览器后台切换与系统减少偏好事件未独立触发验收，原生阶段另验。减少反馈的保留/取消有策略测试及复审证据，180ms精确视觉时序未单独录屏测量。

预览连接在用户新一轮“继续”后中断，开发服务改用隐藏后台进程并恢复到同一loopback端口18768。失败页的data地址被浏览器工具策略阻止操作，另建正常预览页恢复；未改浏览器安全策略。上述工具失败不记作应用功能失败或通过。
