# OTA仅保留最新安装包

更新：2026-09-29。

## 范围

App已有“我的 → 版本与更新”的远程OTA，独立Supabase提供清单和安装包，不依赖电脑在线。本次完善云端发布保留规则，不改Android客户端、业务数据或签名，不发布空版本升级。

发布器先完成新包及公开清单校验，再在原发布锁内清理其他规范版本路径的APK，重新列举确认仅当前包存在。保留其他对象，不清空桶。分页完成后才删除，清理失败可原包原说明重试。新旧包仅在切换过程中短暂共存。

## 验证

只读检查线上清单为0.4.2/code7，OTA目录含6与7两版。先增加行为测试：22项中17通过、5项按预期失败，确认旧实现不清理也不处理清理失败。实现后另补清单变化保护用例，共23项全部通过，包括205版本分页清理、无关对象保留、验证失败不删除、清理失败重试、非法列表拒绝、删除接口假成功后再次检查。

独立审查、CI及线上实际清理结果待补录。不把HTTP夹具当真实云验证；本次Android无改动，不重复声称新的真机安装验收。
