# Android OTA 阶段报告

日期：2026-09-19。用户要求继续完善 OTA，并提供已打开调试的 vivo V2430A（Android 16/API36）。

## 范围与部署位置

业务服务位于独立 Singapore Supabase `skeghmapzrmahxehazlp`，不是电脑本地服务器。OTA 使用同项目专用 `app-updates` 公开读取桶；私有 GitHub 仓库负责源码、CI 与签名构建。没有修改业务数据库、迁移、账号同步或研究函数；百炼继续暂缓，生产 Cron 保持关闭。

客户端新增“我的 → 版本与更新”，独立于登录；提供版本检查、说明、下载进度、取消/重试、完成文件恢复、包级安装权限和系统确认安装。每次下载完成、恢复及安装前检查大小、SHA256、包名、版本、minSdk、固定发布证书及当前安装证书。仅允许项目固定 HTTPS 路径，限制清单/安装包体积并拒绝重定向。

发布器从实际 APK 提取身份并验证签名；APK 按 versionCode 不可覆盖，公开回读核验后才提升最新清单。跨机器发布锁串行化操作，失败重试继续验证公开清单。工作流 `publish_ota` 默认关闭，只有显式开启才发布。详情见 [OTA 运维说明](../OTA_OPERATIONS.md)。
