# UI-D1：水墨武侠核心页面设计稿

日期：2026-09-29。

## 范围

用户请求先给 UI 方案，并同意制作首页、镖库、记录详情三页设计稿。本阶段交付独立 HTML 交互原型、明暗主题和按钮规范；未修改 Android 或后端代码。

交付入口：[设计稿](../design/ink-wuxia/index.html)、[设计说明](../design/ink-wuxia/README.md)。

## 验证证据

- 内置浏览器目视检查桌面三页、明暗配色，以及 390×844 窄屏详情。
- 搜索“山居”返回一条；不存在的关键词显示空结果；目标 + 未确认组合返回两条。
- 点击跑步记录后详情联动；历史两版可展开，日期与示例原话日期一致。
- 编辑空输入呈现邻近错误提示；填写后展示“未写入任何记录”的演示反馈；Escape 关闭弹层。
- 分享预览包含原话、人物、日期和确认状态，未出现该记录私人备注。
- 窄屏测量无横向溢出；可见应用按钮高度均至少 48 CSS px；浏览器 error / warn 日志为空。
- 原型阶段检查了浅色及深色首屏；随本次提交保存的是移除印章后的浅色截图，夜墨配色由 HTML 预览。
- `git diff --check` 通过；未进行 Android 构建验证，本阶段没有改动应用代码。

## 发布与验收边界

设计稿阶段没有运行 Android CI、构建或发布 APK，也未执行 Android 真机验收；后续用户批准与实施证据见 UI-D2。仅启动绑定 127.0.0.1 的本机预览服务。商业级无障碍、性能、字体许可与完整业务闭环属于 Android 实现阶段验收。
