# 宣纸朱砂 · 水墨武侠视觉提案

日期：2026-09-29。状态：第一轮设计稿已获确认，已按批注移除品牌印章，Android 核心页面已完成实现与模拟器验收。

直接用浏览器打开 `index.html`，或访问当前会话本机预览 `http://127.0.0.1:18765/`。页面完全独立，无外部依赖；预览服务退出后仍可直接打开文件。

## 设计方向

以宣纸底、墨色正文和朱砂主按钮建立安静、可读的界面；远山用于品牌识别；根据用户 9 月 29 日批注，移除品牌旁小印章。主标题用宋体，正文用黑体，品牌字单独使用楷体。字体调用设备已有字体，未分发字体文件；Android 使用系统 Serif/SansSerif 字体，不新增字体资源与包体。

首页先呈现待跟进记录与新建入口；镖库把搜索、筛选压缩为清晰工具区，让记录占据主要空间；详情先读原话，再看验证标准、来源、修订历史，原型底部展示分享与编辑；Android 本阶段固定编辑，分享继续使用现有回顾与备份入口。

动效采用短暂入场、明暗过渡、底部弹层出现三种形式。系统要求减少动态时关闭动画。

## 可体验的内容

- 三页总览或单页预览，宣纸与夜墨两套配色。
- 原话、人物、主题搜索；无结果提示；类型和结果组合筛选。
- 待跟进优先 / 录入时间排序；点击记录联动详情。
- 验证标准、来源、历史切换及修订展开。
- 新建 / 编辑布局、空输入错误提示、保存反馈演示。
- 分享卡预览（不展示私人备注）、通知弹层、返回导航。
- 键盘焦点、弹层内 Tab 循环、Escape 关闭；核心操作触控高度至少 48 CSS px。

所有数据为虚构示例，日期固定为 2026-09-29。页面不连接云端、不上传内容、不持久化记录。AI 助手与“我的”仅展示导航反馈，完整编辑页及其余业务页面属于下一轮范围。

## 预览验证

已在 Codex 内置浏览器目视检查明暗主题、桌面三页和 390×844 窄屏详情。窄屏页面及详情容器无横向溢出；可见应用按钮高度检查无小于 48 px 的项目。搜索命中 / 空结果、组合筛选两条结果、记录联动、修订展开、编辑空输入错误与保存反馈、Escape 关闭及分享隐藏备注已验证；浏览器未捕获到 error / warn 日志。

截图 `preview-light.png` 为用户批注后移除印章的浅色首屏。完整页面及夜墨配色请打开 HTML。
