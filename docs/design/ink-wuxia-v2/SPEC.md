# 青绿山水 · 墨气流动

日期：2026-10-03。用户已确认总体方案、UI-D5静态构图及UI-D6实际动态样板；本日以“好的，开始”授权进入UI-D7 Android原生适配。UI-D7正在实施，原生与真机验收另行记载。

## 视觉方向

以一幅连贯的原创青绿山水建立主体：石青、石绿、赭石和墨色皴纹形成近、中、远景，留白承载标题。山体稳定，云雾与墨尘独立运动。山峦不能使用灰度照片拼接、简单三角形或多边形替代。品牌旁不恢复印章。

内容顺序：品牌与日期 → 待回响记录 → 记下原话主动作 → 首页/镖库/AI/我的四导航。正文使用无衬线，品牌与标题使用系统中文衬线/楷体；真实文字不烘焙进山水图片。首页主景约占手机首屏三分之一；编辑等工作页面更安静。

## 交付与确认边界

1. UI-D5：两版完整山水素材、宣纸和夜墨首页静态构图、浏览器窄屏及操作检查。用户确认山水质感、布局与明暗颜色后进入下一步。
2. UI-D6：浏览器动态样板，云雾、24–40个墨尘粒子与少量操作触发朱砂微粒；进入渐显、轻微滚动视差、按钮反馈。供用户确认运动强度和节奏。
3. UI-D7：Android原生适配；装饰绘制不接触业务状态，复用主题、导航与原操作。增加完整/减少/关闭动效；尊重系统动画设置，后台、非首页、遮挡和不可见时停止。
4. UI-D8：本地规定测试/构建、CI设备矩阵和真机性能/数据回归通过后，另行递增版本并通过既有最新包OTA发布。

UI-D5/UI-D6使用固定演示数据，不访问后端、不读手机、不安装或发布APK。0.5.0手机验收仍按UI-D4原边界保留；百炼暂缓、生产Cron关闭。

## 山水素材

内置imagegen生成宣纸整幅山水，再以该画作为编辑目标制作同构图夜景。夜景重新渲染深青地色、山岩矿物颜料和淡青月雾，不直接套灰度/反色滤镜。原画保存PNG；原生阶段按实测解码内存和画面质量处理资源尺寸与格式。

## 验收

- 左侧标题区保持可读，山形、岩石纹理和远近关系可见；底部自然衔接页面。
- 两版一致的结构、操作和构图；正文不压在复杂山景上。
- 浏览器360px窄屏无横向溢出，48px操作目标，主动作与首条记录在手机样板首屏可达。
- 设计稿公开说明动态样板、演示数据与原生未实现边界，不把素材或浏览器验证记作Android/真机通过。
- 动态/原生阶段再单独验收暂停、恢复、减少动效和性能，目标以真机测量为准。

## UI-D6 动态实现细则

原始PNG及静态截图保留。每个山景独立Canvas绘制两层透明谷地云雾、32个归一化固定池墨尘（约0.6–2px），DPR上限2，装饰绘制不超过30fps，不修改山形、正文或命中测试。滚动视差只作用于装饰层，位移上限6px，山图不移动、不露边。

默认完整模式；系统减少设置把完整上限设为减少，并即时响应系统变化。减少/关闭不运行粒子与视差；减少仅有短非循环淡入和颜色反馈；关闭所有过渡和反馈静止。完整入场山景800ms仅淡入、品牌500ms、列表350ms，重播按钮可重复体验。

纯调度器保持最多一个待运行帧，暂停取消并以generation拒绝迟到回调；首帧与恢复首帧dt为0，后续限制0–50ms，不补算后台时间。页面隐藏、主题隐藏、英雄区滚出窗口或手机滚动区、模态打开时暂停并清空动态层；IntersectionObserver、ResizeObserver和页面可见性事件驱动刷新。phone只在状态变化刷新时设置data-motion-mode与data-motion-state，不逐帧写DOM。

录入的完成按钮为“完成预览”；完成、关闭、Escape均丢弃草稿，只有明确完成才在原手机主按钮附近播放最多8个朱砂微粒，450ms渐散。减少模式只改变短暂颜色，关闭模式没有反馈；后台/遮挡立即取消。没有持久化、业务写入或真实保存声明。

Node行为测试与真实浏览器可视验收分别记录，Android、真机、性能和OTA仍属UI-D7/UI-D8。

## UI-D7 原生平台约束

Android系统animator scale为0时有效关闭；0到1之间限制为减少。保留用户选项并即时响应系统设置。真实保存仍立即进入详情、不为动画增加延时；成功朱砂反馈在首次可见返回首页时消费一次，取消与错误不触发。原画作为本地资源，装饰绘制与记录列表重组隔离。实施与证据见[原生计划](../../plans/2026-10-03-ink-native-adaptation.md)。
